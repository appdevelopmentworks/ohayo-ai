# おはようAI

毎朝7時までに、海外の公式発表などからAIの最新ニュースを自動で集め、初心者にもわかるやさしい日本語でまとめて届けるサイトです。マスコットの「ニュー助」が、その日の「AI天気」と大事なニュースを案内します。

収集・選別・要約・ページの作成・公開まで、すべて自動で動いています。

## しくみ

1. **あつめる**: 公式ブログやAPIなど10か所から、新しい情報を集める（GitHub Actions、毎朝6:17）
2. **えらぶ**: AIが世の中への影響で順位をつけ、大事な順に最大20本を選ぶ
3. **まとめる**: 1本ずつ、やさしい日本語の3行と用語メモにまとめる
4. **とどける**: 静的ページを作り直し、Cloudflare Workers で公開する

運用費は0円です（GitHub Actions、Cloudflare Workers、Gemini API の無料枠のみ）。
