| ファイル | 内容 |

## `.dc.html` の読み方

Claude のデザインキャンバス形式のファイルです。専用の実行環境（`support.js`）が必要なため、ブラウザで直接開いても表示されません。実装の参照用として、次のように読みます。

| 場所 | 中身 | 実装での置き換え先 |
| --- | --- | --- |
| `<x-dc>` の中 | 画面のマークアップ（レイアウトはすべてインラインstyle） | `templates/*.html`（Jinja2） |
| `<helmet><style>` | フォント読み込み、キーフレーム、アニメーション用クラス | `public/assets/style.css` |
| 末尾の `<script type="text/x-dc">` の `renderVals()` | サンプルデータ、カテゴリ・重要度の色、タブ、天気、表情の定義 | Pythonのデータ（`data/daily/*.json`）と `render.py`、一部は `app.js` |
| `{{ 名前 }}` | 差し込み | Jinja2 の `{{ 名前 }}` |
| `<sc-for list="…" as="item">` | 繰り返し | `{% for item in … %}` |
| `<sc-if value="…">` | 条件分岐 | `{% if … %}` |
| `onClick="{{ … }}"` | クリック時の処理 | `app.js` のイベント処理（JSなしでも読める作りにする） |

サンプルの記事6本は、2026年10月6〜7日に実際に出たニュースを手作業で要約したものです。本番ではパイプラインが生成したデータに置き換えます。

## ニュー助

配色: ボディ `#7FD9C2`、足 `#5FC4AB`、線と顔 `#1F2D2A`、アンテナ `#FFB547`、ほお `#FF8FA8`、胸の画面の線 `#0B7A65`。

表情は目と口だけを差し替えます（座標は `viewBox="0 0 160 170"` 基準）。

| 表情 | 使う場面 | 目 | 口（path） |
| --- | --- | --- | --- |
| ふつう | 用語メモの説明 | 円 r=6、中心 (64,74) と (96,74) | `M72 86 Q80 93 88 86`（線のみ） |
| びっくり | かみなりの日 | 円 r=8.5、中心 (64,73) と (96,73) | `M76 89 Q80 82 84 89 Q80 96 76 89 Z`（白で塗る） |
| にっこり | はれの日・読了 | 弧 `M57 77 Q64 68 71 77` と `M89 77 Q96 68 103 77` | `M70 84 Q80 97 90 84 Z`（白で塗る） |
| 考え中 | くもりの日・記事がないタブ | 円 r=5、中心 (67,70) と (99,70) | `M74 89 L87 86`（線のみ） |

## AI天気

| 天気 | 表示 | ニュー助 | あいさつ |
| --- | --- | --- | --- |
| かみなり | 大ニュースの日 | びっくり、跳ねる | おはよう！今日は大きなニュースの日。まずはこの3つを押さえよう |
| くもり | ちょっと動きあり | 考え中、首をかしげる | おはよう！今日はちょっと動きあり。この3つをチェックしよう |
| はれ | おだやかな一日 | にっこり、ゆらゆら | おはよう！今日はおだやかな日。この3つだけ読めば大丈夫 |

どの天気にするかは、その日の記事の影響度から決めます（判定の閾値は実装時に決める）。

## レイアウト

- PC幅: 最大幅1120pxの中で、左に天気とニュー助（幅320px目安）、右にニュースカードの2列構成
- カード一覧: `grid-template-columns: repeat(auto-fill, minmax(300px, 1fr))`。今日いちばんのカードだけ横幅いっぱい
- スマホ幅: すべて1列。天気とニュー助 → タブ → カード → 読了 → 仕組み、の順

## 試作と要件の違い

試作は表示を確かめるための簡略版です。実装では要件どおりに作ります。

- タブ切り替え: 試作は短いフェードのみ。要件どおり View Transitions API で並び替える
- 連続で読んだ日数: 試作は「1日目」で固定。ブラウザ内の保存（localStorage）で数える
- 「AILEAPに相談する」ボタン: 問い合わせ先URLが未定のためリンク先なし
- 仕組みの説明: 試作はページ下部に置いている。要件どおり、詳しい説明は裏側ページ（/behind/）に分ける
