# 最新AI情報自動取得 要求定義（案）v1

> 最初の案です（履歴として保管）。最新の要件は [requirements.md](requirements.md) を参照してください。

海外の一次ソースからAIの最新動向を毎朝自動で取得・翻訳・要約し、初心者や非エンジニアでも直感的に理解できるデザインの静的Webサイト（Cloudflare Pages）へ完全無料で配信するシステムの要求仕様です。

---

## 1. システム全体構成

```
[ 一次ソース (RSS/API) ]
  ├ Hugging Face / arXiv / 各社公式ブログ / Reddit
  │
  ▼ (定時起動: 毎朝JST 7:00)
[ GitHub Actions (Ubuntu Runner) ]
  ├ Pythonスクリプト実行 (feedparser / uv)
  ├ Gemini API (gemini-2.5-flash) による日本語化・平易な要約・スコアリング
  └ リポジトリへ news.json を自動コミット＆Push
  │
  ▼ (Git Pushトリガーで自動反映)
[ Cloudflare Pages (静的ホスティング) ]
  └ HTML / CSS / Vanilla JS (または軽量フレームワーク)
  └ ユーザー閲覧画面 (高速・完全無料・スマホ最適化)

```

---

## 2. 機能要件

### 2.1 データ収集機能

* **巡回先**: 信頼性の高い一次ソースに限定し、ノイズやアフィリエイト記事を排除する。
* 開発企業公式: OpenAI Blog, Google AI Blog, Anthropic News
* モデル・論文: Hugging Face Daily Papers, arXiv (cs.CL, cs.AI)
* 実践コミュニティ: Reddit (`r/LocalLLaMA`)


* **実行頻度**: 1日1回（毎朝 JST 7:00 / UTC 22:00）。
* **重複排除**: 過去数日間に取得した記事URLとの照合を行い、差分のみを抽出。

### 2.2 AI処理機能（Gemini API 連携）

* **モデル**: `gemini-2.5-flash`（無料枠内での高速処理）。
* **出力フォーマット**: Structured Outputs（JSON Schema）で厳密にパース。
* **変換要件**:
1. **わかりやすい日本語タイトル**: 難解な英語の直訳を避け、平易な表現にリライト。
2. **小学生でもわかる3行要約**: 「何が起きたか」「何ができるようになったか」「私たちの生活・仕事にどう影響するか」の3点で構成。
3. **初心者向けキーワード解説**: 記事中に含まれる専門用語（例: 推論、ウェイト、量子化、マルチモーダル等）から1つを取り出し、1行で用語解説を付与。
4. **カテゴリ分類**: `注目トピック` / `画像・動画` / `便利なツール` / `新モデル` / `研究・論文` のいずれかに分類。
5. **世間への影響度スコア**: 1〜5段階（★表示用）。



### 2.3 デプロイ・運用自動化

* GitHub Actions上で `public/news.json` を生成。
* 変更がある場合のみGitコミット・プッシュを実行し、無駄なビルド・通知を防止。
* Cloudflare Pagesがリポジトリの変更を検知し、数秒でエッジ環境へキャッシュ配信。

## 3. UI/UX・デザイン要件（初心者・情報弱者向け特化）

専門知識がないユーザーが訪れても圧倒されず、毎朝の習慣としてストレスなく読めるインターフェースを設計します。

### 3.1 ビジュアル・トーン＆マナー

* **脱・サイバー感**: 黒背景に蛍光色の「SF風・ギーク風」デザインを避け、**清潔感のある白ベース＋親しみやすいアクセントカラー（爽やかなブルーまたはミントグリーン）** を採用。
* **文字設計（タイポグラフィ）**:
* フォントサイズは大きめ（本文16px以上）、行間（line-height 1.7以上）を広く確保。
* 視認性の高いユニバーサルデザインフォント（システム標準のゴシック体）を使用。


* **スマホファースト**: 8割以上の閲覧者がスマートフォンである想定で、親指だけでスクロール・タップが完結するカードレイアウト。

### 3.2 画面構成と情報階層

```
+-------------------------------------------------------+
|  ヘッダー: サイト名 ＋ 最終更新日時（例: 今朝7:00更新）    |
+-------------------------------------------------------+
|  【今日の3行まとめ】                                   |
|  今日のAI業界をざっくり一言で把握できるハイライトエリア    |
+-------------------------------------------------------+
|  【カテゴリフィルター】                                 |
|  [すべて] [注目] [画像・動画] [日常で使える] [新モデル] |
+-------------------------------------------------------+
|  ニュースカード一覧                                    |
|  +-------------------------------------------------+  |
|  | [カテゴリバッジ]  重要度: ★★★★☆ (注目)           |  |
|  | 分かりやすい日本語タイトル (大きめ太字)             |  |
|  | ----------------------------------------------- |  |
|  |  * どんなニュース？: ○○○○○○○○○○                 |  |
|  |  * 何がすごいの？: △△△△△△△△△△                 |  |
|  |  * どう変わる？: □□□□□□□□□□                   |  |
|  | ----------------------------------------------- |  |
|  |  💡 用語メモ: 「LLM」とは、文章を理解する頭脳のこと |  |
|  |  [一次ソースを見る (英語外部リンク)]             |  |
|  +-------------------------------------------------+  |
+-------------------------------------------------------+

```

### 3.3 初心者向けUXの工夫

1. **専門用語のツールチップ / メモ**:
* 難解な単語には点線下線を引き、タップすると簡単な説明がポップアップする仕様、またはカード下部に「💡 ひとこと用語メモ」枠を常設。


2. **重要度の直感化**:
* 「スコア5」などの数値表記ではなく、「🌟 今日一番の注目」「💡 押さえておきたい」といった直感的なアイコンラベルを採用。


3. **元ソースへの配慮**:
* 一次ソースリンクは「一次ソース（英語元記事）」と明記し、クリックして英語サイトに飛んでもユーザーが驚かない導線設計にする。


4. **ローディング体験**:
* 静的フェッチ時のチラつきを防ぐため、スケルトンスクリーン（読み込み中のグレー枠）を表示。

## 4. 非機能要件（完全無料・高信頼性）

| 項目 | 要件仕様 |
| --- | --- |
| **ランニングコスト** | **完全無料（0円運用）** |
| **ホスティング制限** | Cloudflare Pages 無料プラン（帯域無制限、月500ビルド制限内：月30回程度利用） |
| **CI/CD制限** | GitHub Actions 無料枠（月2,000分中、月数分のみ消費） |
| **API制限** | Google AI Studio（Gemini API 無料枠・1日15リクエスト前後で制限内に完全収束） |
| **表示速度** | ファーストビュー表示 1秒以内（Cloudflareエッジキャッシュ配信） |
| **外部依存性** | 外部CSSフレームワーク（Tailwind CDNなど）はCDNリンクで軽量読み込み、npmビルド不要構成 |

## 5. 成果物ディレクトリ構成

リポジトリ直下をシンプルな構成に保ち、ビルドステップなしでCloudflare Pagesが直接配信できるようにします。

```text
ai-daily-news/
├── .github/
│   └── workflows/
│       └── update-news.yml   # 毎朝定時実行するActions設定
├── scripts/
│   └── collect_news.py       # RSS取得・Gemini連携・JSON生成スクリプト
├── public/                   # Cloudflare Pages の公開ルート
│   ├── index.html            # 初心者向けUI画面
│   ├── style.css             # クリーンで読みやすいデザイン定義
│   ├── app.js                # news.json を読み込み描画するスクリプト
│   └── news.json             # Actionsによって自動上書きされるデータ
├── requirements.txt          # Python依存ライブラリ (google-genai, feedparser等)
└── README.md

```
